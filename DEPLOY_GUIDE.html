Run Locally (Development)

You need Node.js 18+ installed. Download from nodejs.org

1
Extract and install
unzip edushare-app.zip
cd edushare-api
npm install
2
Configure environment

Edit .env (already included). Default settings work for local dev.

3
Start the server
npm start

Open http://localhost:3001 in your browser

Configure Real Email OTP

Currently the OTP is returned in the API response (demo mode). To send real emails, enable Gmail SMTP:

📧 Gmail SMTP Setup
1
Enable 2FA on your Gmail account
Go to Google Account → Security → Enable 2-Step Verification
2
Create an App Password
Google Account → Security → App passwords → Select "Mail" → Copy the 16-character password
3
Add to your .env or Render environment variables
EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_USER=youremail@gmail.com
EMAIL_PASS=xxxx xxxx xxxx xxxx
4
Update server.js — replace the OTP send section
const nodemailer = require('nodemailer');

const transporter = nodemailer.createTransport({
  host: process.env.EMAIL_HOST,
  port: parseInt(process.env.EMAIL_PORT || '587'),
  secure: false,
  auth: {
    user: process.env.EMAIL_USER,
    pass: process.env.EMAIL_PASS
  }
});

// In the /api/auth/send-otp route, add:
await transporter.sendMail({
  from: `"EduShare" <${process.env.EMAIL_USER}>`,
  to: email,
  subject: 'Your EduShare verification code',
  html: `<div style="font-family:sans-serif;padding:24px">
    <h2 style="color:#1B4FE8">📚 EduShare</h2>
    <p>Your verification code is:</p>
    <h1 style="letter-spacing:8px;color:#1B4FE8">${otp}</h1>
    <p style="color:#64748B">Valid for 10 minutes</p>
  </div>`
});

// Also remove demo_otp from the response:
res.json({ success: true, message: 'OTP sent to email' });

API Reference

🔐 Authentication
MethodEndpointDescription
POST/api/auth/send-otpSend verification code to email
POST/api/auth/verify-otpVerify the 6-digit code
POST/api/auth/registerCreate student account
POST/api/auth/loginLogin, returns JWT token
GET/api/auth/meGet current user (auth required)
PUT/api/auth/profileUpdate profile (auth required)
📚 Materials
MethodEndpointDescription
GET/api/materialsList all materials (filter: course, subject, search, sort)
GET/api/materials/myCurrent user's uploads
POST/api/materialsUpload material (multipart/form-data)
GET/api/materials/:id/downloadDownload file + increment counter
DELETE/api/materials/:idDelete material (owner or admin)
📂 Courses & Admin
MethodEndpointDescription
GET/api/coursesList all courses with material counts
POST/api/coursesCreate course (admin only)
PUT/api/courses/:idUpdate course (admin only)
DELETE/api/courses/:idDelete course (admin only)
GET/api/admin/statsDashboard analytics (admin only)
GET/api/admin/usersAll students with stats (admin only)
DELETE/api/admin/users/:idRemove student (admin only)
POST/api/feedbackSubmit feedback message
🔑 Using the API from external apps

All protected routes require the Authorization header:

Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

Example — upload a material from JavaScript:

const form = new FormData();
form.append('course', 'ict');
form.append('subject', 'Technology');
form.append('description', 'My revision notes');
form.append('file', fileInput.files[0]);

const res = await fetch('https://edushare-api.onrender.com/api/materials', {
  method: 'POST',
  headers: { Authorization: 'Bearer ' + token },
  body: form
});
const material = await res.json();

Convert to Android App

🤖
WebView APK
Wrap your web URL in a native Android shell. Easiest approach — works immediately.
Easiest
⚡
Capacitor (Ionic)
Convert HTML/JS to a proper Android app with native features like camera, notifications, offline.
Recommended
📱
PWA Install
Add manifest + service worker and students can "Install to Home Screen" — works like an app with no Play Store needed.
No build needed
⚡ Capacitor Setup (Recommended path)
npm install -g @ionic/cli
npm install @capacitor/core @capacitor/cli @capacitor/android

# Init Capacitor (run in edushare-api folder)
npx cap init EduShare com.edushare.app --web-dir public

# Add Android platform
npx cap add android

# Set your live URL in capacitor.config.json:
# "server": { "url": "https://edushare-api.onrender.com" }

# Open in Android Studio
npx cap open android
In Android Studio: Build → Generate Signed Bundle/APK → share the .apk file with students via WhatsApp or Google Drive.
